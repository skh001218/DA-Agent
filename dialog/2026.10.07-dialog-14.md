# 워크트리 변경 정리 및 CLI 공통 개선 이관

- 사용자 요청: 추천 순서대로 백업 → 공통 개선 선별 → Codex CLI 검증 → 기존 워크트리 정리.
- 주요 결정: Codex CLI를 사용하므로 Gemma 모델 전용 오류 수정은 중단한다. 기존 변경은 삭제하지 않고 보관한다.
- 완료: 기존 변경 91개 파일을 `codex/analysis-recovery-backup`의 `9efe9f1`에 저장. 최신 `origin/main`의 `3f90051`에서 새 관리 워크트리와 `codex/analysis-cli-common` 브랜치 생성.
- 구조 확인: docs, scripts, specs/examples, src, template, tests가 모두 존재. 이동이나 삭제 없음.
- 이관 후보: 실제 데이터 총량 검사, 구체적인 설계 오류 피드백, 의미 검토에서 거절된 초안 보존과 전체 설계 재시도.
- 제외: Gemma 전송·쿼터·모델 설정과 전용 실험. RecipePatch 프로토콜은 필요가 확인될 때까지 백업에 보관.
- 남은 작업: 공통 코드와 회귀 테스트 이관, 실제 CLI 검증, 결과 기록과 커밋, 무시된 .local 파일 별도 보존 후 기존 워크트리 아카이브.
- 운영 반영: PR, push, main 병합, 배포, Discord 메시지 전송은 요청 범위에 없음.
