# 대화 및 작업 기록

- 사용자 요청: 광범위한 실무 요청을 특정 분석·보스 레이드로 유도하지 않고 검색한 실제 사례를 근거로 다양하게 출제하도록 수정한다. 이전 출제 영향과 초급·중급·고급의 실패 및 품질도 점검했다.
- 사용자 근거: 같은 주제만 나오면 실제 업무에도 해당 주제만 있다고 오해할 수 있다. 토큰을 더 사용해도 실제 업무 사례를 검색하는 흐름을 원한다. 판단은 나의판단과근거.md에 기록했다.
- 확인: 최근 5개 출제의 서명이 프롬프트에 들어간다. 과거 원문 SQL·대화는 들어가지 않는다. 기존 프롬프트가 추상적 요청을 보스·스테이지·장비로 고정했다. 실제 6건 감사 결과와 실패 원인은 tests/reports 및 tests/artifacts/difficulty-audit-2026-10-06에 보존했다.
- 구현 중: 실제 Google 검색 → grounding 검증 → 서로 다른 사례 후보와 최근 주제 중복 회피 → 난이도별 합성 문제 → SQL 검증 → 출처 공개. src/da_agent/case_research.py 신설, api_provider/task_generation/adaptive_tasks/task_contracts 및 app.js/training.js 수정. 검색 실패를 가상 사례로 숨기지 않는다. 검색 결과와 선정 사례는 재시도 시 고정한다. 호출 상한은 8회다.
- Spec: specs/019-source-backed-task-generation.md, 검증 완료 후 진행도 갱신 예정.
- 검증: 검색·출처·기존 API/품질 검사 53개 통과 1개 건너뜀. 전체 검사 309개 통과 8개 실패; 8개는 기존 training-001/v1 기본 패키지 부재(package_unavailable)로, 격리 데이터베이스에 패키지를 준비하여 재검증 예정이다. Python 구문 및 JavaScript 구문 통과. 추가 DB 검색 실패·재시도·취소 검사 작성했다.
- 외부 제한: 실제 Gemini 검색은 기본 모델 및 별도 검색 모델 모두 RESOURCE_EXHAUSTED(429), 현재 키의 할당량 초과로 실제 출제 성공을 검증할 수 없다. 비밀값을 출력하지 않았다. 실제 실패 화면과 모의 응답을 사용한 출처 저장·재개 화면을 구분하여 검증할 예정이다.
- 환경: 기존 da-agent-app-1은 8087. 현재 소스를 읽기 전용 마운트한 da-agent-v3-verification은 8088. 현재 테스트는 별도 recorder schema를 사용한다. 사용자 DB·패키지를 삭제하거나 덮어쓰지 않는다.
- 남은 작업: 기본 패키지를 갖춘 격리 전체 회귀, 추가 DB 검사, 출처 UI 실제 브라우저 확인, 검색 모델 환경 설정 점검, 안내 문서와 Spec 갱신, 서비스 반영 가능 여부 점검. 실 검색의 할당량 제한은 명시한다.
