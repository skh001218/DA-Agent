# Codex CLI 연결 작업 기록

- 사용자 요청: Gemma API 대신 Codex 구독을 CLI로 연결하는 Spec 작성 및 구현.
- 사용자가 밝힌 선택 이유: 기존 구독을 활용해 API 비용을 줄이기 위해. `나의판단과근거.md`에 기록.
- 주요 결정: ChatGPT 로그인된 공식 Codex CLI를 subprocess로 실행. Gemma 기본값은 유지하고 codex_cli를 선택 가능하게 구현. API 키 자동 전환 없음. read-only·ephemeral 실행과 자격증명 환경 분리 적용.
- 완료: Spec 048, CLI 어댑터, Discord 설정/오류 안내, Docker CLI 설치, 별도 Compose, main 배포 옵션, 검증 스크립트, 자동 테스트, 설정 문서.
- 변경 파일: src/da_agent/codex_provider.py 및 Discord 관련 모듈, scripts/deploy_discord.py, scripts/verification/verify_codex_*.py, Dockerfile.discord, compose.discord.codex.yaml, docs/codex-cli-setup.md, specs/048-discord-codex-cli.md, tests/automated/test_codex_provider.py 및 배포 테스트, tests/reports/spec048-codex-cli-2026-10-07.md.
- 검증: 자동 테스트 684개 통과/80개 건너뜀, 별도 PostgreSQL Discord 핵심 테스트 58개 통과. 실제 구독으로 출제→조회→용어 설명→평가→재개 성공. 새 평가 프로필 승인이 없어 점수는 보류, 피드백 저장은 성공.
- 초기 실제 요청 하나는 기존 독립 검증에서 plan_invalid로 거절되었으며 실패 세션과 진단이 보존됨. 이후 별도 요청은 핵심 흐름 성공.
- 상태: codex/discord-codex-cli 브랜치, 아직 미커밋. 운영은 b1505888b649e9f3457e04e17d1e6175e4c709f5 main/Gemma 그대로.
- 남은 작업: 변경 검토, PR/CI, main 병합/CI, main 기준 배포, 실제 Discord 확인, Spec/보고서 갱신.
- 비밀정보: .local 파일과 자격증명은 Git에 넣지 않음. 테스트 컨테이너 da-agent-spec048-db는 작업 종료 후 정리.
