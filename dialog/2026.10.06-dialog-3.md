# 대화 기록

- 요청: Discord 과제 가독성 개선, 대화 문제 진단·수정, topic 제한 의도 확인. 현재는 데이터 사전과 자연어 조회 결과를 기호로 만든 표 대신 실제 정렬된 표로 표시하도록 구현 중.
- 완료: 비공개 스레드에 과제 6개 섹션 표시, 대기 조회 전환·조건 확인·외부 서비스 오류 구분 개선. 110개 테스트 통과, 실제 Discord 조회 40명/30명/75% 확인.
- 조사: Discord는 대표 tutorial 고정 과제이고 사용자 지정 과제 생성은 연결되지 않음. 웹에는 별도 적응형 생성 존재.
- 결정: 표는 Pillow와 한글 글꼴로 PNG 생성하여 Discord 파일 첨부, 설명·NULL·빈 결과·수집 한계는 텍스트로 유지. 기존 저장 근거 값 보존.
- 관련 파일: src/da_agent/discord_{bot,query,service,transport}.py, tests/automated/test_discord_{conversation,readability,transport}.py, specs/028-discord-readable-task.md, specs/029-discord-conversation-recovery.md, docs/discord-setup.md.
- 남은 작업: 표 구현·테스트·이미지 확인·봇 컨테이너 교체·실제 Discord 화면 확인.
