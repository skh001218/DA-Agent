## 재사용 방법

- 이미지 파일을 PPT나 문서에 직접 삽입할 수 있습니다. 기존 캡처는 해상도·형식을 그대로 보존했습니다.
- 발표자료에서 화면 일부만 보이도록 잘랐던 이미지도 이 폴더에는 전체 원본으로 저장했습니다. 필요한 영역은 삽입한 문서에서 선택해 사용하세요.
- 원본 파일은 보존하고, 새로운 캡처나 가공본은 다른 이름으로 추가합니다.
- 새 캡처 이름은 `기능-YYYY-MM-DD-장면.png`처럼 기능과 촬영일을 함께 적습니다.

## 출처와 확인 범위

- 정리일: 2026-10-08
- 출처: 프로젝트 루트의 [DA-Agent Project.pptx](../../DA-Agent%20Project.pptx)
- 발표자료 원본 5장의 정확한 촬영일은 미상입니다. 검증 캡처 7장의 원본은 `tests/artifacts`에 보존했습니다.
- 새 촬영 8장은 실제 로컬 웹과 Discord UI를 열어 저장했습니다. 웹 훈련을 재개해 기존 초안·근거·리뷰 복원을 확인했고, Discord는 기존 질문·답변 기록과 연습 방식 선택 UI를 확인했습니다.
- 새 촬영 시 AI 리뷰·새 출제·새 보고 제출은 실행하지 않았습니다. 저장된 리뷰와 대화 기록을 열어 보여 주는 화면입니다.
- 모든 이미지를 직접 열어 내용과 가독성을 확인했습니다. 이미지 형식·해상도, 원본 복사본의 바이트 일치와 목록 링크도 검사했습니다.
- [manifest.json](manifest.json)에 이미지별 촬영일·출처·페이지·해상도·SHA256을 기록했습니다. 발표자료 원본에는 자르기 비율도 포함합니다.

발표자료 9~10페이지의 평가 품질 개선 방향과 막대·선 그래프 등의 시각화 도구 연결은 개선 제안입니다. 구현된 기능의 스크린샷으로 포함하지 않았습니다.
