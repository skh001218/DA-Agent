# Discord SQL 연습 문제 — 공통 출력 템플릿

- 상태: 로컬 구현. 운영 배포는 별도 요청 범위.
- 목적: SQL 연습 문제의 가독성을 높이고 문제마다 같은 항목·순서로 출력한다.
- 적용 대상: 생성형 SQL 문제와 기존 SQL 문제의 첫 안내·재개 안내.

```text
📌 {문제 제목}
난이도: {초급 / 중급 / 고급} · 연습 유형: SQL

🎯 1. 문제 목표
{배경}
{직접 작성할 SELECT가 계산해야 할 목표}

📚 2. 사용할 데이터
첨부한 데이터 사전 이미지를 누르면 확대할 수 있습니다.
{저장된 자료 안내}

{기존 데이터 사전 요청과 동일한 이미지: 테이블별 행 단위·설명·컬럼명·자료형}

🔎 3. 계산 조건
• 기간·시간 기준: {공개된 기간, 시간대, 시작·종료 경계}
• 계산 단위: {집계 대상의 단위}
• 대상·필터: {포함·제외 조건과 공개 가정}
• 그룹 기준: {그룹 열 또는 전체 집계}
• 계산 정의: {공개된 집계 정의; 비율이면 분모·분자 각각 표시}
• 예외 처리: {중복·누락·NULL·0 분모·빈 결과·그룹 출력에 관한 필수 조건}

📤 4. 출력 형식
• 열 이름과 순서: {출력 열을 순서대로 나열}
• 자료형·단위: {숫자형·문자형·날짜형 및 비율 단위 등의 공개 규칙}
• 행 정렬: {공개된 정렬 규칙}

📝 5. 제출 방법
1. 별도로 제공된 sql 코드 블록 틀을 복사해 풀이를 작성하세요.
2. 틀 안내 메시지에 답장해 실행하세요. 수정할 때도 전체 SQL을 새 답장으로 보내세요.
3. 실행 결과를 확인한 뒤 /submit로 최종 평가를 요청하세요.
• 입력 제한: 코드 블록과 설명을 포함해 1,900자.
• {추가 설명 필요 여부; 고급의 검산 설명 요구를 해당 문제의 공개 조건대로 표시}
• 도움말: /help — 데이터 사전·평가 기준·개념 도움.
• 답장 수신이 제한되면 /sqlrun text:코드블록을 사용하세요.

문제 정보
• 데이터 버전: {저장된 데이터 버전}
• {원본 SQL 노출 이력 — 기존 연결 과제에서 해당하는 경우}
```

## 출력 규칙

- 구역 제목·번호·순서는 고정한다. 난이도와 주제에 따라 각 항목의 내용만 바꾼다.
- 공개된 문제 정보와 SQL 계약으로 내용을 채운다. 모델에게 자유롭게 최종 표시 형식을 작성하게 하지 않는다.
- 풀이를 결정하는 조건은 줄이거나 데이터 사전에만 숨기지 않는다. 긴 조건은 여러 항목으로 나눠 표시한다.
- 공개 조건을 임의로 추론하거나 추가하지 않는다. 해당하지 않는 항목은 `해당 없음`, 저장되지 않은 항목은 원문을 보존하고 미확정 상태를 표시한다.
- 비율 문제는 분모·분자 정의를 각각 독립된 줄로 표시한다. 비율이 아닌 문제에는 해당 집계 정의를 표시한다.
- 사용할 데이터는 기존 `dictionary_tables`와 `render_table_png`로 만든 이미지를 2번 구역 바로 뒤에 첨부한다. 이미지를 모두 보낸 뒤 3~5번 구역과 입력 틀을 전송한다. `/help` 데이터 사전 요청에서도 같은 이미지를 제공한다.
- 이미지 렌더링·첨부가 실패하면 기존 텍스트 대체 안내로 동일한 테이블 설명과 컬럼 정보를 전달한 뒤 나머지 구역을 보낸다.
- 필수 관계·행 단위·기간 경계·출력 열 순서·NULL 규칙·고급 설명 요구를 보존한다. 정답 SQL·정답 수치·비공개 검증 자료는 포함하지 않는다.
- 입력용 코드 블록은 기존 별도 메시지로 유지하여 답장 실행 흐름을 보존한다.
- Discord의 실제 전송 길이 제한에 따라 구역이나 줄 경계에서 나누며 내용을 삭제하지 않는다.
- 첫 안내와 재개 안내는 같은 렌더러를 사용한다. 구조화 정보가 없는 저장 과제도 기존 공개 원문을 보존한다.
- 실행 템플릿: `src/da_agent/discord_sql_presentation.py`. 구역별 공개 정보 저장: `discord_generated_sql.py`, `discord_sql_practice.py`. 전송 연결: `discord_service.py`의 SQL 재개 응답.
