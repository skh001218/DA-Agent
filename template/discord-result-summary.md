# 분석 결과 PDF 요약 템플릿

목표: 3쪽을 읽으면 **무엇을 발견했고, 왜 그렇게 판단했으며, 다음에 무엇을 개선할지** 알 수 있게 한다.
기본 구성은 검토용 시안이다. 기존 상세 PDF는 별도로 보존한다.

## 1쪽 - 결론과 행동

| 구역 | 작성 규칙 | 권장 분량 |
| --- | --- | --- |
| 제목 | 과제명. 배경 설명은 넣지 않는다. | 2줄 이내 |
| 범위 | 기간(KST), 대상 수, 관측 조건 | 2줄 |
| 핵심 결론 | 발견한 차이 + 판단. 인과 효과와 관측 차이를 구분한다. | 2~3문장 |
| 대표 수치 | 단위가 있는 한글 열 제목. 분모·분자/대상·비율 함께 표시 | 2~4행 |
| 우선 행동 | 대상 → 조사/개선 행동 → 확인 기준 | 3항목 이내 |
| 주요 한계 | 결과 해석을 바꾸는 한계만 본문에 남긴다. | 2~3줄 |

## 2쪽 - 분석 근거

| 구역 | 작성 규칙 | 권장 분량 |
| --- | --- | --- |
| 추가 근거 | 결론을 바꾸는 세부 비교. 원문 숫자를 다시 확인한다. | 4~6행 |
| 근거 해석 | 표에서 읽어야 하는 사실과 의미. 인과를 단정하지 않는다. | 2~3문장 |
| 비교 조건 | 분모·관측 시간·구성 차이·데이터 무결성 점검 | 짧은 3항목 |
| 판단의 한계 | 결과 해석을 바꾸는 한계 | 2~3줄 |

## 3쪽 - 평가 피드백

| 구역 | 작성 규칙 | 권장 분량 |
| --- | --- | --- |
| 평가 피드백 | 항목 / 모델 관측 / 다음 개선 행동. 긴 평가 인용문은 원문으로 보낸다. | 5행 |
| 다음 확인 | 제출 보고서와 후속 답변에서 실제 다음 행동을 압축한다. | 2줄 |
| 평가 상태 | 보류·미검산·사람 검토 여부처럼 오해하기 쉬운 상태 | 3줄 이내 |
| 원문 | 상세 기록으로 이동할 링크와 자료 성격 | 2줄 |

## 작성 원칙

- 요약문은 원문에 근거해 작성자가 편집한다. 이 생성기는 내용을 자동 요약하거나 새 사실을 만들지 않는다.
- 수치는 선택한 저장 조회 결과에서 가져온다. 비율은 0.5 대신 50%처럼 읽기 쉽게 표시한다.
- 비율의 분모, 단위, 관측 기간, 합성 자료 여부는 생략하지 않는다.
- 관측 등급과 확정 점수를 구분한다. 총점 보류를 100점으로 바꾸지 않는다.
- 배경·질문·조건 목록의 반복, UUID, 긴 평가 정책, 전체 보고서와 평가 인용문은 상세 원문에 둔다.
- 표·문장이 페이지를 초과하면 입력을 다시 편집한다. 자동 잘라내기나 글자 축소는 하지 않는다.
- 더 많은 근거가 필요하면 상세 원문이나 별도 부록을 이용한다.

## 로컬 시안 생성

예제 데이터: `template/discord-result-summary.example.json`.
작성자가 `title`, `meta`, `conclusion`, `metrics`, `priorities`, `caveat`, `details`, `evidence_insight`, `evidence_notes`, `feedback`, `next_step`, `evaluation_status`, `source_url`, `source_note`를 수정한다.
표는 `headers`와 같은 열 수의 `rows`, 표 아래 출처 설명인 `caption`을 갖는다.

```powershell
python scripts/preview_result_pdf.py --data template/discord-result-summary.example.json --output output/pdf/concise-result-preview.pdf
```

첫 PDF 생성 시 PDF 스킬의 artifact operation marker를 먼저 실행한다. 생성기는 3쪽 초과 시 출력 파일을 쓰지 않는다.
운영 연결에서는 같은 레이아웃에 저장된 공개 원문의 문장과 조회 결과를 발췌한다. 기본 `PDF 다운로드`는 3쪽 학습형이며 `상세 원문 PDF`로 전체 내용을 확인한다. 원문·행·열 생략 범위를 표시하고 추가 모델 호출은 하지 않는다. 운영 상태와 실제 다운로드 검증은 Spec 055 및 운영 검증 보고서를 따른다.
