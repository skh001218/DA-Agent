# Discord 포럼 결과 — 핵심 요약형 테스트 초안

- 상태: 초기 로컬 시안을 바탕으로 운영용 렌더러에 연결. 배포·실제 Discord 검증 상태는 Spec055 참조.
- 목적: 결론, 주요 근거, 평가, 다음 행동을 한 카드에서 읽기.
- 자료: 기존 공개 제출·저장 평가. 초기 확인본은 수동 발췌였으며 운영용은 저장된 구조화 필드·라벨·수치/비교 문장에서 추가 AI 호출 없이 발췌한다.

```text
📊 [과제명] · [참가자]

결론
핵심 결론 1문장

핵심 근거
• 주요 결과·수치 최대 3개

평가
점수 또는 보류 상태 · 사람 검토 상태
잘한 점 1개
개선점 1개

다음 행동
가장 먼저 할 일 1개

[전체 보고서·평가 PDF 다운로드]
```

## 테스트 규칙

- 본문은 900자 이내. 문장 길이를 제한한 경우 말줄임표로 표시하며 전체 원문은 PDF에 유지한다.
- 결론 120자, 근거 각 90자·최대 3개, 잘한 점/개선점 각 90자, 오류 안내 90자, 다음 행동 120자를 기본 한도로 삼는다.
- 평가 보류는 점수보다 우선한다. 보류를 0점으로 표시하거나 임의로 잘한 점을 만들지 않는다.
- 확인된 계산 오류가 있으면 평가 아래에 한 줄로 표시한다.
- SQL 결과는 통과 항목 수와 검증 범위를 표시한다. 분석 평가 점수를 새로 만들지 않는다.
- 점수·평가·제출 원문은 수정하지 않는다. 항목별 평가 근거, SQL, 후속 답변, 긴 상태 안내는 기존 전체 PDF에 보존한다.
- 테스트 화면은 실제 Discord 메시지의 로컬 모사이며 실제 Discord 게시·버튼 상호작용 검증과 구분한다.
