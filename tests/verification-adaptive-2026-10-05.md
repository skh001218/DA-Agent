## 발견한 실패와 보완

- 최초 화면 스크립트는 클릭 핸들러 등록 전에 요청을 클릭하고 존재하지 않는 draft-status를 기다렸다. 실제 요청 생성이나 저장 실패와 구분하고 핸들러 등록 대기·save-status로 수정했다. [초기 실패](adaptive-browser-2026-10-05/initial-failure.json)를 보존했다.
- 계정 성향이 섞이는 상세 로그, 정답 normal/suspicious 분류, 계정별 요약의 참조 중복, 계정별 grain에 식별자가 없는 설계를 발견했다. 생성 recipe까지 독립 검토하고, 라벨 비공개·유일 키·참조 그룹·식별자·시간 순서 규칙을 보완했다. 보호 규칙 전의 [이전 결과](adaptive-browser-2026-10-05/pre-label-guard-result.json)는 최종 적합성 통과로 사용하지 않는다.
- 모델이 첫 컬럼 외에도 id 생성기를 사용하거나 현상 표본 확인 조건을 누락했다. schema 오류 위치/종류를 바탕으로 최대 한 번 수정하며, 여전히 부적합하면 미공개한다. [schema 실패](adaptive-browser-2026-10-05/schema-failure.json)를 보존했다.
- 수정 호출의 마지막 메시지가 model 역할로 끝나 Gemini가 api_request_invalid를 반환했다. 마지막 user 메시지로 수정을 요청하도록 고쳤다. 모델 호출 사이 간격과 전체 최대 3회 상한을 유지했다.
- 불필요한 상세 로그를 요약과 독립 생성해 불일치가 발생했다. 원 요청을 충족하는 최소 데이터와 선언 문법 예시를 안내하도록 개선했다. 불일치한 설계는 공개하지 않는다.
- SQL AVG(bigint)의 실제 NUMERIC 결과가 문자열로 직렬화되어 검산이 실패했다. 유한한 숫자 문자열만 Decimal로 비교하도록 보완하고 NaN 거부를 검증했다.

## 남은 범위

선언 생성기 밖의 복잡한 데이터 관계·인과 시뮬레이션과 모든 분석 주제에 대한 적합성을 보장하지 않는다. 자동 검토는 의미적 판단에 실패할 수 있다. 고정 검산 계약과 다른 타당한 SQL·분석은 미확인으로 구분하며 자동으로 모두 검증했다고 주장하지 않는다.

전 유형·난이도의 반복 평가 편차, 사람의 오진/미탐·대안 인정·난이도 적합성, 다른 PC/ARM·실제 5명 파일럿은 남아 있다. 기존 PRD 5/11과 출시 검증 상태는 별도로 유지한다.
