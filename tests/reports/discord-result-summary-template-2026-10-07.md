- 초기 스트레스 확인에서 900자 초과를 발견해 결론/다음 행동 120자, 근거/평가 설명/오류 90자로 조정했고 재검증에 통과했다.

## 자료와 보존

- 분석: 기존 `discord-pdf-citations-2026-10-06/public-submission.json`의 공개 훈련 보고서·평가를 사용했다. 합성 훈련 데이터로, 실제 업무 지표가 아니다.
- SQL: 기존 `spec035-2026-10-06/public-submission.json`의 저장 공개 SQL·4행 결과·평가를 사용했다.
- 보류/계산 오류: 표시 경계 상황을 확인하기 위해 분석 자료를 복사해 만든 명시적인 파생 테스트 사례다. 실제 평가 기록을 변경하거나 실제 새 평가로 취급하지 않는다.
- 요약 문장은 사람이 원문을 선택한 발췌와 저장 수치 기반 정리다. 임의 보고서에서 핵심을 자동 선택하는 기능은 구현·검증하지 않았다.
- 공개 제출 입력을 전후 비교해 불변임을 확인하고 각 사례의 전체 공개 자료를 별도 JSON으로 보존했다.
- PDF에는 기존 전체 렌더러를 사용했다. 모든 공개 카드 제목, 요약에서 제외한 가설·대안 설명·데이터 신뢰성·후속 검증·후속 답변, SQL 본문이 포함되는지 확인했다. 공개 근거 ID는 기존 PDF 참조 렌더링 정책에 따라 사람이 읽을 수 있는 참조로 표시된다.
- 생성한 16쪽 전체를 PNG로 렌더링해 확인했다. 한글, 표, 보고서, 평가가 잘리거나 겹치지 않았다.
