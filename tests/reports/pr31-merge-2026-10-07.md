- 9개 충돌 파일을 해결했다. 최신 main의 SQL·고급 판단·countTokens·pending 예약 기능은 기존 통합본에 이미 포함되어 있어 출제 개선 코드와 함께 보존했다.

- PR #30의 화면·JUnit·운영 검증 자료는 그대로 보존했다. 과거 배포 보고에는 현재 통합 보고로 연결되는 후속 기록을 추가했다.

## 검사

- 격리 PostgreSQL 17.4와 전체 자동 테스트: **663 passed / 46 skipped**, [최종 JUnit](pr31-merge-all-2026-10-07.xml). 전용 Discord 조회 DSN도 제공해 이전 657/52 실행보다 DB 조회 6개를 추가 실행했다.
- [최초 검사](pr31-merge-initial-2026-10-07.xml)는 662 passed / 46 skipped / 1 failed. 임시 learner 역할의 기본 읽기 전용 설정 때문에 SELECT 권한만 가진 계정의 쓰기 거절 검사에서 예상한 InsufficientPrivilege 대신 ReadOnlySqlTransaction이 발생했다. 임시 역할의 기본 설정을 바로잡고 전체를 다시 검사했다. 제품의 SELECT 권한과 SqlRunner의 읽기 전용 트랜잭션은 유지했다.
- 최종 실패·오류 0개. 기존 Starlette/httpx 사용 경고 1개. 생략된 환경 의존 검사는 실행 완료로 계산하지 않는다.
- 충돌 표식 0건, `git diff --cached --check` 통과. 운영 DB를 테스트에 사용하지 않았다.
- 제품 소스가 이전 운영 반영본과 동일해 기존 [화면·운영 검증](generation-integration-2026-10-07.md)을 유지한다. 이번 작업은 운영 재배포나 실제 모델 재시도를 추가하지 않는다.
