## 구현

- `discord_results.py`: 해당 보고 버전의 `evidence_refs`에 연결된 성공 결과만 화이트리스트로 내보냄. 컬럼·행·집계 조건·불완전성 표시 포함, SQL·비공개 필드·다른 조회 제외.
- `discord_pdf_evidence.py`: 저장 행으로 그래프 생성, 기존 `render_table_png`를 재사용해 표 이미지 생성. 그래프는 벡터로 확대 시 선명함. 긴 표를 작은 이미지로 축소하지 않고 행 분할 가능한10pt PDF 표로 전환.
- 기존 Discord 첨부 PNG 파일을 복사한 것은 아니다. 동일한 저장 결과와 기존 표 렌더러로 PDF용 제목·소수점·ID 표시를 조정해 다시 생성했다.
- 선택한 조회 ID는 PDF에서 “조회 결과1”처럼 도표를 참조. 과제 대화 ID도 원래 과제 공간을 안내하는 이름으로 표시. DB 원본과 포럼 카드의 원문은 보존.
- 그래프에 적합하지 않은 결과는 표만 제공. NULL·범위 밖 백분율 제외 시 안내. 잘린 결과는 전체 조회로 오인하지 않도록 표시.
