## 확인한 동작

- 실제 `discord.py` CommandTree 등록에서 `practice` 필수와 두 선택지, `/sqlrun`, 선택 `/submit execution_id` 확인. 누락·지원 밖 유형은 이벤트 claim·데이터 준비 전에 거부.
- 초급 전체, 중급 채널별, 고급 가입 주차×채널별 과제. 각 문제의 주 데이터와 중복·기간 경계·분모 자료를 준비하고 Python 고유 사용자 계산과 기준 SQL을 출제 전에 대조.
- 학습자가 제출한 CTE 대안 SQL을 그대로 실행해 동등 결과 인정. 미리보기와 영구 저장 전체 결과 구분.
- 없는 열 오류 → 전체 SQL 수정 → 성공 → 평가 → 재시작 후 기록 복원. 시도/평가 버전과 기존 성공 시도 명시 선택 보존.
- 빈 틀·주석만·잘못된 언어·여러 블록·닫힘 누락·길이 초과 거부. 원문 틀을 Markdown escape 없이 전송하고, 등록된 봇 메시지 답장만 실행하는 전송 검사.
- 실행 안내 텍스트뿐 아니라 결과 표의 첨부 메시지·행별 텍스트 대안도 수정 답장 대상으로 연결. 데이터 사전은 풀이 결과 답장 대상으로 연결하지 않음.
- 상수 출력, 조인 중복, 관측 종료 포함 오류를 검증 데이터에서 판별. 결과 수집 제한·검증 DB 연결 거부는 의미 판정 보류.
- 중복 메시지 ID에 실행 시도 중복 없음. 완료 평가 후 잘못된 실행 ID 요청은 과거 결과 게시로 전환하지 않음.
- 유형 없는 기존 분석 세션 연결, SQL 열람 이력·출처 보존, 다른 소유자 접근 거부. 기존 분석 조회·보고·평가 회귀.
- SQL 결과 카드에 기준 SQL·검증 스키마 미포함. 공개 결과는 제출 SQL·실행 결과·항목별 판정·도움/노출 이력을 포함하고 총점·독립 역량을 주장하지 않음.
