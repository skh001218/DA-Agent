## 자동 검증

- Python 컴파일·JavaScript 문법 검사·Docker 이미지 빌드 통과.
- 전체 테스트: 실제 PostgreSQL 포함 97개 통과. 기존 의존성의 폐기 예정 경고 2개는 테스트 실패가 아니다.
- 모의 AI로 실제 SQL 표본 5종·3회 반복, 사람 판정·재개·요청 재전송 중복 방지·버전 충돌·동시 실행 차단·중단 시 완료분 보존·응답 실패를 확인했다.
- v1/v2 패키지 모두 정상 SQL·대안 SQL은 실제 기준 결과와 일치하고 중복·미관측 표본은 분모 오류를 재현했다.
- 빈 다음 행동 승인, 수정 보고서 없는 보완 승인, 판정 근거 없는 미충족 승인 차단.
- 파일럿 미저장 SQL·결과 비수집, 코드 중복 차단, 최신 사람 판정이 다운로드에 포함되는지 확인했다.

## 실제 화면 확인

- 별도 운영자 화면 진입, 패키지 선택, 15회 평가 시작, 진행 상태·완료 결과·실패·점수 범위 표시.
- 판정 메모 입력·저장 후 새로고침 복구. 최종 사람 판정은 미판정으로 유지했다.
- UI_TEST라는 검증용 참가자를 새 훈련에 연결하고 입력 저장·복구·빈 필수 입력 오류를 확인했다.
- 최초 보고서 v1과 수정 보고서 v2를 제출하고 파일럿 화면에서 두 내용을 비교했다. 실제 학습자 보고서로 기록하지 않았다.
- 단계 이동·SQL 성공 상태만 이벤트로 기록하고 미저장 SQL 표식 `UI_UNSAVED_QUALITY_TEST`는 내보내기에 없음을 확인했다.
- 검증·파일럿 JSON 파일을 실제로 다운로드하고 최신 메모·이벤트 내용을 확인했다. 초기 Blob 내보내기 관측이 불안정해 서버의 attachment 응답으로 변경 후 확인했다.
- [화면 캡처](../artifacts/quality-screen.jpg). 검증용 참가자·훈련은 확인 후 정리하며 실제 5명 파일럿으로 집계하지 않는다.
