## 확인 범위와 남은 작업

이번 배포는 코드 반영·시작·DB 연결·명령 동기화·화면 옵션 표시까지 확인했다. 실제 Discord에서 과제를 전송하여 출제·SQL 실행·평가·재개하는 전체 흐름과 실제 Gemma 생성 성공은 이번에 실행하지 않았다. 기존 429·HTTP500과 난이도 의미 검사·필수 practice 서비스 검증 관련 미완료 항목은 배포로 해결됐다고 표시하지 않는다.

사용자가 확인할 첫 행동: `#da-agent`에서 `/training`을 선택하고 `practice:SQL 연습`, `text:튜토리얼 신규 가입자 3단계 완료율`로 시작하여 비공개 스레드에 SQL 작성 틀이 나타나는지 확인한다. `text`는 `/training` 옵션이며 별도 `/text` 명령은 없다. Message Content Intent가 false이므로 SQL 답장은 봇 멘션을 포함하거나 `/sqlrun`을 사용한다.

## 재시작 / 재배포

현재 프로젝트 루트에서 실행한다. 기존 DB 볼륨을 삭제하지 않는다.

```powershell
docker compose --env-file C:/Users/Administrator/.codex/worktrees/discord-mvp/DA-Agent/.local/discord-runtime/compose.env -p da-agent-discord -f compose.discord.yaml -f .local/deploy-spec035-036/compose.deploy.yaml up -d --no-deps bot
```

코드 변경 후에는 같은 인수의 `build bot`을 먼저 실행한다. 이전 Compose/PDF overlay만으로 다시 실행하면 오래된 이미지로 돌아갈 수 있으므로 현재 배포 구성을 사용한다. 롤백은 별도 overlay에서 bot의 image를 위 보관 태그로 지정해 `up -d --no-deps --no-build bot`을 실행한다.
