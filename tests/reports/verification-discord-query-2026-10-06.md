## 기준 결과

고정 데이터 가입 코호트 3명: 단계3 기간내 완료 사용자 1명, 단계3 도전 사용자 2명. 동일 사용자의 완료 2회는 1명으로 집계한다. 가입자 분모 완료율 1/3, 도전 사용자 분모 완료율 1/2. 도전 이벤트 수 4회(다른 단계 포함), 단계3 반복 시도 수 1회. 날짜 종료 경계의 시도는 제외한다.

D7 표본 관측 완료 분모4명·분자3명. 같은 날짜 2세션은 1명이며 D6 접속은 D7로 보지 않는다. 가입23일 사용자 D7인 30일이 관측 종료(30일 제외)에 도달하므로 분모에서 제외한다. 분모0 결과는 NULL이다. 별도 주간 재방문 기준 사용자2명·재방문2명으로 D7과 구별한다.

채널별 집계·필터·빈 결과·0 분모·KST 날짜 경계, 공개 컬럼 누락·지원 밖 지표·잘못된 시간대·기간·단위·SQL 변조 차단을 검증했다. 초급 선택지는 concept_hint, 중급/고급 중립 질문은 request_confirmation으로 구분한다. 이전 조건은 명시적 재사용 때만 병합하며 원래 요청/확인 답변을 유지한다.

실제 SqlRunner는 미리보기1행과 전체수집2행을 구별하며 runner.get을 실행 직후 복사한다. 복사 실패는 성공 근거로 사용할 수 없다. 최대1회 동일 SQL 일시 오류 재시도와 각 실행 SQL·runner 오류 보존을 확인했다. 문법·차단·시간 초과는 재실행하지 않는다.

## 제한과 후속 확인

모델 언어 해석의 실제 품질·실제 Discord 메시지 출력과 사용자 조작은 미확인이다. 본 검증은 고정 연산의 의미·실행 안전성과 대체 API 계약 검증이며 실제 모델 품질 승인이나 Discord 출시 승인으로 간주하지 않는다. 단계별 반복 시도 수는 재도전을 포함하므로 그 자체로 수집 중복을 입증하지 않는다. 원인 판단은 사용자가 수행한다.
