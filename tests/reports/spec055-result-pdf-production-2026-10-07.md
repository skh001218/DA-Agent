# 3쪽 학습형 결과 PDF 운영 적용 검증

- 요청: 선택한 3쪽 학습형 템플릿을 운영 다운로드에 적용.
- 범위: 분석 결과의 기본 요약 PDF, 상세 원문 PDF, 기존 게시글 보완, Git·CI·main 배포·실제 다운로드.
- 기존 SQL 연습 형식과 저장 평가·원문 보존.

## 로컬 구현과 검증

- 공개 제출 카드의 완결된 문장을 발췌하며 새 모델·SQL 실행 없음.
- 저장 조회 행으로 표를 작성. 비율의 분자/분모를 검증할 수 없으면 원값 유지.
- 생략 행·열·긴 문장 표시. 3쪽 초과 시 글자 축소 없이 더 짧은 발췌를 제공.
- 첫 게시글에 요약·원문 2개 첨부. 기본 버튼은 요약 우선, 별도 버튼은 원문 제공.
- 이전 원문 첨부는 보존하고 요약만 한 번 보완. 재제출/재개 시 재생성·중복 게시 방지.
- 두 버튼의 서버·작성자·사용자 접근 권한을 같은 정책으로 검사. 기존 버튼 custom ID 유지.
- 요약 생성 실패·업로드 한도 실패 시 평가 보존, 게시 완료로 기록하지 않음.
- 관련 65개 통과. 전체 793개 통과 / 83개 건너뜀 / 기존 Starlette 경고 1개.
- 실제 E2E 보고서의 채널 2행·경험 4행을 모두 유지한 3쪽 생성 회귀 확인.
- 초기 Windows 최종 렌더링 3쪽의 표·한글·여백·발췌 표시·점수 보류 확인. 운영 Nanum 폰트와 다운로드 결과는 배포 뒤 추가 확인.

## Git·CI·운영 상태

| 단계 | 상태 | 근거 |
| --- | --- | --- |
| 코드·로컬 검증 | 완료 | 위 테스트와 `test_discord_pdf_summary.py` |
| PR·main CI | 진행 중 | PR 생성 대기 |
| main 기준 운영 배포 | 검증 대기 | `python scripts/deploy_discord.py --apply` 사용 |
| 실제 Discord 다운로드 | 검증 대기 | 기존 제출 재개 → 같은 글 갱신 → 요약/원문 다운로드 → 재개 재사용 확인 |

운영 배포와 실제 다운로드가 완료될 때 이 기록 및 Spec 055를 갱신한다.
