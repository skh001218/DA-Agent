## 구현 결과

SQL과 분석은 같은 필수 text 입력을 받아 출제한다. SQL은 공개 계산 단위·관계·조건·출력 열을 확정하고, 비공개 Python 기대 결과와 앱이 컴파일한 SQL을 실제 DB에서 대조한다. 본 자료·시드와 표본 크기가 다른 두 자료·빈 데이터에서 학습자 SQL의 전체 결과를 비교한다. 그룹 값이 고정된 경우에도 분모/분자 크기를 바꾸어 상수 결과를 걸러낸다. 숫자형·NULL·타임스탬프·열/행 수를 확인하고 행 순서는 무관하다. 준비된 표본 범위의 결과 검증이며 모든 SQL의 동치 증명은 아니다.

고급은 직접 SQL 결과와 검산 방법 설명을 별도로 평가한다. 기준 SQL과 기대 결과는 공개 과제에 포함하지 않으며, 첫 제출 전 정답 공개를 막는다. 기준 기록을 잃어도 사전·저장 풀이를 열람할 수 있지만 채점·해설은 보류한다. 기존 text 없는 고정 과제와 저장 세션은 유지한다.

현재 한 문제는 한 분석 지표를 계산하며 지원 연산은 count/distinct/sum/avg/min/max/ratio와 FK 조인·그룹 집계다. 목표를 지원 연산으로 충족하지 못하면 원래 주제를 임의로 바꾸지 않는다. text 기반 SQL의 기존 완료 분석 연결은 명시적으로 미지원 안내한다.

## 리텐션 검증

공통 정의는 가입 한국 날짜+7일의 D7 재접속이다. 이용자별 합성 관측 요약에서 관측 일수>=7인 이용자를 분모로 사용하고, 무접속자는 분모에 남기며 미관측 이용자는 제외한다. 원본 접속 로그 풀이를 검증했다고 표현하지 않는다.

| 난이도 | 계산 범위 | 고정 표본의 실제 DB 결과 | 실제 Codex 출제 결과 |
| --- | --- | --- | --- |
| 초급 | 전체 D7 리텐션 | 생성·CTE 동등 풀이·4개 자료 채점·재개 통과 | 생성·실행·채점·재개 통과, 1행 |
| 중급 | 유입 채널별, FK 조인 | 생성·CTE 동등 풀이·4개 자료 채점·재개 통과 | 생성·실행·채점·재개 통과, 2행 |
| 고급 | 가입 코호트와 채널별, FK 조인, 검산 설명 | 생성·실행·4개 자료·설명 채점·재개 통과 | 생성·실행·채점·재개 통과, 4행; 설명 포함 4/4 충족 |

관측 일수 필터 제거 오답, 고정 숫자 풀이, 없는 열 오류와 수정, 공개 표 외 접근 차단, 빈 표, 정답 노출 정책, 출제 취소 후 권한 회수, 확인 질문, 비공개 기준 누락, DB 접속 장애의 판정 보류를 테스트했다. 구매액 합계 문제도 같은 출제·채점 경로에서 통과했다.

실제 모델 검증에서 다음 결함을 찾아 수정하고 재검증했다.

- 기존 검사기가 ‘로그인’과 ‘합성 요약이며 원본 로그 집계가 아님’을 원본 로그 제공 약속으로 오인했다. 로그인 정의·원본 미제공 설명은 허용하고 실제 원본+요약 제공 약속은 파생 자료를 요구한다.
- 고급 출제의 공개 설명이 분모 0 코호트 행을 요구했으나 지표는 대상 행이 있는 그룹만 반환했다. 독립 검토가 출제를 보류했다. 그룹 출력 계약을 프롬프트에 명시하고, 의미 검토 실패 후 재시도는 같은 초안을 반복 검토하지 않고 다시 설계하도록 수정했다. 새 설계는 독립 검토를 통과했다.
- 검산 설명 평가에 공개 스키마·사전이 빠져 실제 존재하는 observation_id를 없는 열로 판단했다. 공개 스키마·사전·목표를 검토 요청에 포함하고 회귀 테스트를 추가했다.

검산 답변 자체의 기간 경계 누락과 빈 그룹/전체 집계 혼동도 피드백에 따라 보완했다. 최종 설명은 구체적인 계정키 중복·조인 증폭, 기간/관측 경계, 그룹별 분모/분자·빈 자료를 확인할 계획이며, 수행 완료로 주장하지 않는다. 설명 검토는 모델 평가이고 사람 품질 검토·학습 효과 확인과는 구분한다.
