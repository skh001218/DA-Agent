# 프로토타입 검증 기록

- 검증일: 2026-10-03 (Asia/Seoul)
- 환경: Windows AMD64, Docker Desktop, Linux AMD64 Python3.12.10 / PostgreSQL17.4
- 범위: 기존 Spec001~004의 문제1 훈련 흐름. PRD의 문제2·3 전체 MVP 완료를 뜻하지 않는다.
- 구현 방식: 공통 API·서버는 루트에서, 데이터·웹·인증은 서로 다른 관리 워크트리와 서브 에이전트에서 구현한 뒤 커밋을 통합했다.

## 자동 확인

실제 PostgreSQL 포함 테스트72개 통과. DB 없는 호스트 실행은67개 통과, DB 통합5개는 건너뜀. tests/test_churn.py, test_packages.py, test_sql_policy.py, test_auth.py, test_review.py, test_integration.py를 사용했다. Starlette/httpx의 테스트 도구 교체 예정 경고가 있으나 테스트 실패는 없다.

실제 DB 패키지 검증기는 v1·v2 기준 SQL과 독립 Python 집계가 일치함을 확인했다. 각 버전에서 빈 코호트 및12개 경계 유저도 실제 SQL로 확인했다. 같은 배포를 다시 적재·검증하여 기존 DB 내용을 유지함을 확인했다.

혼합 ID·버전, 파일 변조·경로 이탈·기준자료 누락 차단을 테스트했다. 조회는 공개 표에 제한하고 쓰기·시스템 표·외부 파일 함수·설정 변경·다중문을 차단했다. 조회0행, 문법 오류, 실행 제한, 최대 행 수와 부분 결과, 큰 정수·numeric·UTC 직렬화를 확인했다.

## 실제 화면 확인

[실행 화면](http://127.0.0.1:8087). agent-browser의 전용 da-prototype 세션으로 조작했다.

- 문제1 v2 시작, 서술 입력 자동 저장, SELECT count(*) 실제 실행 및200명 표시.
- 실행A 선택 저장, 실행B 미저장 후 새로고침: A만 복구하고 SQL 편집기와B 결과는 사라짐.
- 보고서 초안·저장 근거 선택 후 새로고침: 서술과 근거 선택 복구.
- 보고서 v1 제출, 리뷰 요청 실패, 수정 보고서 v2 제출: 두 제출본과 실패 리뷰 보존.
- 서버 재시작 후 이전 미저장 실행 저장: 만료 안내, 원래 화면 결과 유지, 자동 재실행 없음.
- 앱·DB 로그 및 영구 기록에 미저장 검증용 marker가 없고 localStorage/sessionStorage는 비어 있음.
- 정적 파일·화면 표시를 다시 확인하고 보고서/데이터 사전의 표시 오류를 수정함. 브라우저 오류 목록은 비어 있음.

브라우저 검증 자료는 prototype-report.png와 prototype-home.png를 참고한다. 홈 스크린샷은 초기 통합 상태이며 보고서 스크린샷은 최종 표시를 갱신했다. 테스트용 훈련 기록 일부와 화면 검증용 시도는 로컬 기록 DB에 남아 있다.

## 아직 확인하지 않은 항목

- 실제 ChatGPT 계정 로그인·권한 승인·컨테이너 콜백·실제 모델 조회와 코칭/리뷰 완료 응답.
- 실제 AI 리뷰5개 표본·3회 반복의 평가 품질과 일관성. 현재 점수/근거 형식 검증은 모의 응답 테스트다.
- 다른 PC의 Git 체크아웃·Compose·패키지 지문·재개·별도 로그인, ARM 환경.

화면에서 ChatGPT 연결을 눌러 직접 로그인·승인한 뒤 짧은 코칭/리뷰를 요청하는 것이 다음 실제 확인 행동이다. 해당 성공 검증 전에는 Spec003·004의 대기 항목을 완료로 변경하지 않는다.
