# DA-Agent — 데이터 분석 훈련 에이전트

## 프로젝트 소개

DA-Agent는 사용자가 데이터 분석을 훈련할 수 있도록 돕는 에이전트입니다. 에이전트가 분석 문제를 제시하고, 사용자가 해당 문제를 분석하여 결과를 제출하면, 에이전트가 제출된 분석 결과를 판단하고 평가합니다.

## 목적

사용자가 직접 문제를 분석하고 평가를 받는 과정을 통해 데이터 분석 역량을 기를 수 있도록 돕습니다.

## 핵심 기능

### 1. 분석 문제 제시

에이전트가 사용자에게 데이터 분석을 연습할 문제를 제시합니다.

### 2. 사용자 분석 결과 제출

사용자는 제시된 문제를 분석하고, 분석 과정과 결과를 에이전트에게 제출합니다.

### 3. 분석 결과 평가

에이전트는 사용자가 제출한 분석 결과를 문제의 요구사항에 비추어 판단하고 평가합니다. 사용자는 평가를 통해 자신의 분석을 돌아보고 개선할 부분을 확인합니다.

## 사용 흐름

1. 에이전트가 분석 문제를 제시합니다.
2. 사용자가 문제에 대해 데이터 분석을 수행합니다.
3. 사용자가 분석 과정과 결과를 제출합니다.
4. 에이전트가 제출된 내용을 판단하고 평가합니다.
5. 사용자가 평가를 바탕으로 분석을 개선하며 훈련을 이어갑니다.

## 프로젝트 폴더 구조

```text
DA-Agent/
├─ README.md          # 프로젝트 소개
├─ docs/              # PRD 등 제품 관련 문서
├─ scripts/           # 기능 생성 및 검증 자동화 스크립트
├─ specs/             # 기능별 Spec 문서
│  └─ examples/       # 완성된 Spec 예시
├─ src/               # 소스 코드
├─ template/          # 반복 사용하는 문서 템플릿
└─ tests/             # 자동 테스트와 수동 검증 자료
```

## 향후 설계할 사항

문제 1의 데이터·제출·기록·기술 구성은 specs/001~004에 정의했고, 200명 로컬 프로토타입을 구현했습니다. 문제 2·3과 실제 AI 평가 품질은 후속 검증 범위입니다.

## 프로토타입 실행

[실행 안내](./docs/prototype-runbook.md)를 따라 Docker Compose로 시작합니다. 기본 접속 주소는 [DA-Agent](http://127.0.0.1:8087)입니다.

문제 시작, PostgreSQL 조회, SQL 선택 저장, 초안·근거 재개, 보고서 수정 제출을 구현하고 실제 화면에서 확인했습니다. [검증 기록](./tests/verification-2026-10-03.md)에 확인 결과와 남은 항목을 기록했습니다. 실제 ChatGPT 계정 승인·완료 응답과 다른 PC 실행은 검증 대기입니다.


현재 LLM 테스트 경로는 [Gemini API 설정](docs/gemini-setup.md)을 따른다. ChatGPT 로그인 접근 거부에 대한 대안으로 사용자가 선택했으며, 실제 키 설정·모델 호출·품질은 별도로 검증한다.
