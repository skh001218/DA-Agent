# DA-Agent — 데이터 분석 훈련 에이전트

## 프로젝트 소개

DA-Agent는 사용자가 데이터 분석을 훈련할 수 있도록 돕는 에이전트입니다. 에이전트가 분석 문제를 제시하고, 사용자가 해당 문제를 분석하여 결과를 제출하면, 에이전트가 제출된 분석 결과를 판단하고 평가합니다.

## 목적

사용자가 직접 문제를 분석하고 평가를 받는 과정을 통해 데이터 분석 역량을 기를 수 있도록 돕습니다.

## 핵심 기능

### 1. 분석 문제 제시

에이전트가 사용자에게 데이터 분석을 연습할 문제를 제시합니다.

### 2. 사용자 분석 결과 제출

사용자는 제시된 문제를 분석하고, 분석 과정과 결과를 에이전트에게 제출합니다.

### 3. 분석 결과 평가

에이전트는 사용자가 제출한 분석 결과를 문제의 요구사항에 비추어 판단하고 평가합니다. 사용자는 평가를 통해 자신의 분석을 돌아보고 개선할 부분을 확인합니다.

## 사용 흐름

1. 에이전트가 분석 문제를 제시합니다.
2. 사용자가 문제에 대해 데이터 분석을 수행합니다.
3. 사용자가 분석 과정과 결과를 제출합니다.
4. 에이전트가 제출된 내용을 판단하고 평가합니다.
5. 사용자가 평가를 바탕으로 분석을 개선하며 훈련을 이어갑니다.

## 향후 설계할 사항

문제 1의 데이터·제출·기록·기술 구성은 specs/001~004에 정의했고, 200명 로컬 프로토타입을 구현했습니다. 현재는 PRD-v2의 요청 기반 첫 사용 구간을 추가했습니다. 고정 문제 2·3 계획은 PRD-v2로 대체했으며 실제 AI 평가 품질은 후속 검증 범위입니다.

## 프로토타입 실행

[실행 안내](./docs/prototype-runbook.md)를 따라 Docker Compose로 시작합니다. 기본 접속 주소는 [DA-Agent](http://127.0.0.1:8087)입니다.

문제 시작, PostgreSQL 조회, SQL 선택 저장, 초안·근거 재개, 보고서 수정 제출을 구현하고 실제 화면에서 확인했습니다. [검증 기록](./tests/verification-2026-10-03.md)에 확인 결과와 남은 항목을 기록했습니다. 실제 ChatGPT 계정 승인·완료 응답과 다른 PC 실행은 검증 대기입니다.


현재 LLM 테스트 경로는 [Gemini API 설정](docs/gemini-setup.md)을 따른다. ChatGPT 로그인 접근 거부에 대한 대안으로 사용자가 선택했으며, 실제 키 설정·모델 호출·품질은 별도로 검증한다.

## 평가 품질·파일럿 검증

[운영자 검증 화면](http://localhost:8087/static/quality.html)에서 문제 1의 5종 표본을 3회씩 실제 모델로 평가하고, 점수·피드백·사람 판정을 비교·저장할 수 있습니다. 실행 버튼을 누르면 총 15회의 AI 리뷰를 요청하며 API 비용이 발생할 수 있습니다. 회차 실패와 점수 편차를 표시하고 판정 메모·버전·결과를 JSON으로 내보냅니다.

파일럿 탭에서는 실제 참가자의 훈련을 연결하고 도움·중단·다음 수정 행동을 기록하며 최초·수정 보고서를 비교합니다. 미저장 SQL과 결과는 수집하지 않습니다. 이 화면은 로컬 운영자용 별도 페이지이며, 학습자의 일반 훈련 화면에 검증 자료를 넣지 않습니다.

[명세](./specs/005-quality-and-pilot.md)와 [검증 결과](./tests/verification-quality-2026-10-03.md)를 참고하세요. 검증 도구 구현과 실제 AI 평가 품질·파일럿 성공은 별도로 관리합니다.

## 요청 기반 첫 사용 버전

[훈련 화면](http://127.0.0.1:8087)에서 “접속 데이터로 중급 분석 오류 수정 문제 내줘”처럼 요청합니다. 난이도와 사고 과제를 직접 선택할 수도 있습니다.

- 현재 지원: D1~D7 미재접속 계산, 분석 오류 수정, 업무 요청 구체화. 이미 검증된 users/sessions 데이터를 재사용합니다. 새 분야·데이터 자유 생성은 후속 범위입니다.
- 업무 조건 확인, 실제 SQL·선택 저장, 일반 대화·임시 코칭, 제출·리뷰·수정·재개를 연결했습니다. SQL 결과 자동 코칭은 선택해서 켤 수 있고 API 사용량이 발생합니다.
- 설계 과제는 SQL 제출이 필수가 아닙니다. 리뷰 품질은 시험 운영이며 반복 평가·사람 판정 승인 전입니다.
- 운영 이벤트 조회·JSON 내보내기와 훈련 삭제 API를 구현했습니다. 삭제 확인창 취소의 최종 화면 확인은 대기입니다.

[공통 계약](./specs/006-request-training-contracts.md), [첫 사용 구간](./specs/007-request-training-first-use.md), [검증 결과](./tests/verification-request-training-2026-10-04.md)를 참고하세요. 실제 DB 회귀 검증은 테스트 폴더를 컨테이너에 복사한 뒤 `python scripts/verify_request_training.py /tmp/da-tests`로 실행합니다. 이 명령은 별도의 임시 기록 스키마를 사용하며 AI 호출은 검증용 응답으로 대체합니다.
