## 목적과 결정

사용자는 간단한 요청으로도 문제를 제공하고, 추가 조건이 필요하면 요청문에 적는 방식을 선택했다. 난이도와 SQL 수준 외 선택 항목, 작은 지원 범위·시험 과제·다음 훈련 제안 안내, 기존 계산 훈련 시작을 제거한다.

## 동작

- 요청문, 난이도, 선택 SQL 수준과 훈련 준비 버튼을 제공한다.
- 과제와 분야는 `auto`, 데이터 모드는 기존 기본값 `adaptive`로 전송한다. 추가 조건은 원 요청문을 통해 전달한다.
- 지원 상태·추천 안내 및 추천 시작·변경 버튼, 기존 패키지 시작 화면과 해당 조회를 제거한다.
- 추가 확인, 준비 취소, 재시도, 학습 상태 관리와 기존 훈련 이어 하기는 유지한다.
- 홈은 ‘새 훈련’과 ‘이어 하기’ 탭으로 나눈다. 기본은 새 훈련이며 기존 문제 목록은 이어 하기 탭에서만 보인다. 탭 전환은 요청 입력을 보존하며 `?home=resume`으로 새로고침 후 이어 하기 탭을 유지한다.
- 기존 문제를 열고 ‘훈련 목록’으로 돌아오면 이어 하기 탭을 표시한다. 홈 탭과 분석·보고서·리뷰 탭의 동작은 각각 분리한다. 홈 탭은 좌우 화살표·Home·End 키로도 전환한다.
- 출제 후의 데이터·과제 설명 및 서버 계약은 이번 화면 변경 범위 밖이다.
