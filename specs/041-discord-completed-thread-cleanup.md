## 목적과 조건

`/submit` 및 `/resume`에서 완료된 과제의 보고서·평가 카드가 DA-Result에 모두 게시되고 게시 상태가 저장되면 전용 비공개 과제 스레드를 삭제한다. 결과 포럼 게시글은 삭제하지 않는다. 기존 스레드를 일괄 삭제하지 않는다.

- `completed`이며 평가가 보류되지 않은 과제만 대상이다. 평가 보류·부분 게시·게시 실패는 과제 스레드를 보존한다.
- 먼저 부모 채널에 결과 링크와 과제 ID를 남기고 명령 응답을 전달한다. 안내가 실패하면 삭제하지 않는다.
- 삭제 직전 저장된 소유자 세션의 스레드 ID·완료 상태·마지막 평가 ID를 확인한다. SDK에서 비공개 스레드·서버·소유자 참가 및 권한을 다시 검증한다.
- 삭제 권한 부족·연결 오류는 게시 실패와 구분해 안내한다. 완료 게시 기록과 DB 보고서·평가를 보존하며 부모 채널의 `/resume session_id:...`으로 재시도한다.
- 삭제 후 완료 게시된 과제의 `/resume`은 부모 채널에서 기존 포럼의 전체 게시를 다시 확인·복구하고 결과 링크를 안내한다. 과제 스레드를 새로 만들거나 모델을 다시 호출하지 않는다.
- 포럼 요약은 과제 ID를 표시한다. 삭제되어 끊기는 과제 링크는 제공하지 않으며 기존 첫 카드도 재게시 시 갱신한다.

## 문제점과 사용상의 변화

스레드의 Discord 대화·첨부파일과 과거 메시지 링크는 삭제 후 다시 열 수 없다. DB에 저장한 보고·평가·대화 등의 기록은 유지하지만 모든 Discord 대화나 첨부파일의 완전 백업은 아니다. 평가 근거 ID의 검토는 저장 기록을 사용해야 한다.

완료 과제의 개인 스레드에서 `/question` 등 추가 명령을 사용할 수 없게 된다. 결과에 대한 의견은 포럼 댓글에서 이어가며 현재 댓글은 봇 코칭 명령으로 처리되지 않는다. 부모 채널의 결과 링크는 해당 채널 독자에게 보이지만 DA-Result 자체의 접근 권한을 확대하지 않는다.

봇에는 부모 채널 발언 및 스레드 관리 권한이 필요하다. 게시 후 결과 글을 누군가 삭제하면 자동 대체 글을 만들지 않고 운영자 연결 복구를 안내하는 기존 정책을 유지한다.
