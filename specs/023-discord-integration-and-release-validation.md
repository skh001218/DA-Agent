## 연결 범위

019 사용자 기록과 진행 제어, 020 조회 엔진, 021 교육 계약, 022 전송 계층을 독립 워크트리에서 통합한다. 별도 봇 프로세스가 내부 Python 서비스를 호출한다. 현재 웹의 app.py, 정적 파일, 설정, 의존성, 운영 컨테이너와 DB를 수정하지 않는다. 웹 API를 외부에 노출하지 않는다.

현재 대표 과제는 tutorial(튜토리얼) 하나다. 새 사용자 첫 과제는 기준 관측, 완료 후 새 시작은 후속 데이터 변형으로 준비한다. 동일 기준이라는 이유만으로 자동 비교 승인하지 않으며 사람의 비교 승인 전 성장 자료 부족으로 표시한다. 도움 이후 평가를 무보조 성과로 계산하지 않는다. 도움 전 사용자 원문·메시지 ID를 보존한다.

## 검증 완료의 의미

API는 계약에 맞는 대체 응답을 사용하고 실제 데이터 계산·권한은 별도 PostgreSQL에서 실행한다. 대체 평가의 점수가 실제 모델의 의미 판단 품질을 보장하지 않는다. 실제 SDK 명령 등록은 로그인 없이 확인한다. 실제 Discord 화면/권한/상호작용·Gemini 의미 품질·사람의 교육 품질 승인은 출시 필수 조건이며 미완료다.

## 수동 확인 시작

docs/discord-setup.md에 따라 별도 DB·봇 환경을 설정한 후 사용자 A가 부모 채널에서 `/training topic:tutorial difficulty:intermediate`를 실행한다. 비공개 스레드에 업무 목표·데이터 사전·배점·도움 정책이 나타나는지 확인하고 사용자 B가 접근/조작할 수 없는지 확인한다. 이어 조회·보고·평가·재개 및 오류 표본을 검증 기록에 추가한다.
