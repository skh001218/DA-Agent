## 요구사항과 선택

- 사용자 요청은 포럼 또는 가독성 개선이다. 현재 문제별 비공개 스레드에서 진행하는 방식에 읽기 쉬운 안내를 적용한다.
- 새로운 포럼 채널 생성과 공개 범위 변경은 이번 범위에 포함하지 않는다.
- 최초 시작과 /resume에서 동일한 안내를 제공한다. 새 문제를 만들지 않고 저장된 문제를 이어간다.
- 기간의 종료일 제외, 관측 종료, 데이터 단위와 컬럼, 필수·추가 평가 조건, 핵심 오류, 등급, 비평가 항목, 중복 감점 방지, 도움 정책을 보존한다.
- 일반 답글 수신은 기존 Message Content 설정을 따른다. 현재 실행은 슬래시 명령으로 이어간다.

- d93f 워크트리 소스로 da-agent-discord-bot 이미지를 빌드했다. 기존 discord-mvp 실행 설정에서 --no-build --no-deps bot으로 봇만 교체했고 Gateway ready를 확인했다.
- 저장 과제 1ac939a2-ced5-4519-b2bc-e57a031ebe93의 스레드 1556891645016809593에 새 안내를 게시했다. 이전 메시지는 삭제하지 않았다.
- 6개 메시지의 길이·내용·멘션 차단을 실제 Discord REST 재조회로 확인했다. DB 과제 문서는 게시 전후 동일하다.
- Chrome의 실제 Discord에서 문단·줄바꿈과 데이터 사전 표시를 확인했다. 새 탭에 과제 링크를 열어 사용자가 열어 둔 채널 생성 창은 유지했다.
- 조회·보고·최종 제출을 실제 계정으로 실행하지 않았다. DB를 요구하는 5개 통합 테스트는 실행 환경 설정이 없어 건너뛰었다.
- 재빌드는 변경 소스가 있는 d93f 워크트리에서 해야 한다. 기존 discord-mvp 경로에서 이전 소스를 빌드하면 안내가 되돌아갈 수 있다.
