## 목적과 확정 범위

사용자는 봇 자체의 하루 호출 제한 해제를 요청했다. DISCORD_DAILY_CALL_LIMIT=0을 무제한으로 정의하고 운영에 명시적으로 적용한다. 기본값 30과 양수 한도는 다른 운영을 위해 유지한다. 사용량 기록을 지우지 않는다. 요청별 출제 호출 상한·제한된 재시도·취소 확인·모델 직렬화·Codex 구독 한도는 변경하지 않는다.

## 구현·검증 조건

- 설정은 0 또는 양의 정수만 허용한다. 무제한에서도 UTC+9 날짜별 호출 횟수를 원자적으로 누적한다.
- 이미 당일 30회를 쓴 사용자도 무제한 전환 후 새 호출을 예약할 수 있다. 양수 한도를 다시 적용하면 기존 누적 기록을 기준으로 제한한다.
- 배포의 --daily-call-limit 0은 DB·비밀·인증·기타 환경을 보존하면서 봇의 해당 설정만 변경한다. 잘못된 값은 빌드·운영 변경 전에 거절한다.
- main 기반 배포·CI·지문·복구 규칙을 유지한다. 운영 설정을 --status에서 확인한다.
- 실제 Discord의 실패 스레드 1557248613069885500에서 /retry를 확인한다. 출제 품질 성공 여부와 호출 제한 해제 성공 여부를 구분한다.
