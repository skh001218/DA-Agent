## 목적과 사용자 결정

SQL 연습 문제의 가독성을 높이기 위해 템플릿을 고정한다. 사용자는 사용할 데이터를 기존 데이터 사전 요청에서 제공하는 이미지로 바꾸도록 선택했다. 문제 제목·난이도와 1. 문제 목표, 2. 사용할 데이터, 3. 계산 조건, 4. 출력 형식, 5. 제출 방법 순서를 고정한다.

## 구현 계약

- 모델의 최종 자유 형식 출력 대신 저장된 공개 정보로 템플릿을 채운다. 정답·비공개 검증 데이터는 노출하지 않는다.
- 기존 `objective`, SQL 계약, 채점·실행은 보존한다. 신규 문제는 공개 안내 구역을 함께 저장하고 이전 저장 문제는 원문을 조건 구역에 그대로 표시한다.
- 데이터 사전 이미지 생성기를 재사용한다. 2번 구역 뒤에 이미지를 첨부하고 3~5번 구역과 답장용 코드 블록을 이어 보낸다.
- 첨부 실패 시 기존 텍스트 대체 기능으로 공개 정보를 보존한다. 긴 메시지는 기존 전송 분할과 멘션 방지 정책을 적용한다.
- 고급 검산 설명·미수행 검산 계획 표시, 기간 경계, 빈 자료와 NULL 규칙을 유지한다.
- 처음 요청은 로컬 구현과 검증이었으며 후속 요청으로 PR·main 병합·운영 배포·실제 Discord 확인까지 범위를 확대했다. 운영 작업 1개를 추가하여 분모를 3개에서 4개로 변경했다.
