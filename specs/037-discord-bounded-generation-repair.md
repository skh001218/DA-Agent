## 목적과 계약

2026-10-07의 중급 요청은 역방향 PK→로그 조인 설계를 반복했고, 수정 초안 누적으로 내부 입력 예산을 초과했다. 최신 초안과 현재 오류만 모델에 전달한다. 전체 실패 이력은 기존 비공개 checkpoint에서 보존한다. 사용자 요청·선택 난이도·분석 단위·분모·정답 라벨 정책을 임의 변경하거나 검증을 완화하지 않는다.

추가 모델 설계 호출 없이 한 요청 안에서 업무→행 단위/관계→지표 순서를 지정하고, 수정 요청에서는 서버가 표 선언으로 계산한 허용 FK 연결과 행 단위·유일키를 제공한다. 사용자 잔류율을 로그 비율로 자동 전환하지 않는다. 계정별 요약도 미관측 계정 누락이 있으므로 전체 대상 보장 또는 범위·한계를 명시한다.

가상 출제 프롬프트는 웹 검색 기반 프롬프트와 분리한다. 스키마의 설명·기본값·중첩 제목·불필요한 공백만 줄이고 required, enum, 경계값, 형식과 properties 필드명은 유지한다. 서버의 Recipe·자료·독립 검산·적합성 검토는 그대로 적용한다.

분당 예산은 기존 운영 코드의 SQLite·14,000/65초 계약 및 pending 열을 보존한다. INSERT의 열 이름을 명시하며 4열 기존 DB를 사용량 손실 없이 갱신하고 5열 운영 DB도 재사용한다. countTokens를 우선 사용하고 계산 실패 시 UTF-8 추정치를 적용한다. 실제 전송 전 예산 회복은 최대130초 대기하며 generateContent를 자동 재시도하지 않는다. 진행 중 예약을 유지하고 응답 완료부터65초 사용량을 보존한다. 입력 크기 거절·분당 예산 대기·인증 오류 등 외부 추론 호출 전 실패는 요청/일일 추론 호출 횟수를 소비하지 않는다. 외부 전송을 시도한 실패는 계산한다. 일일 제한 또는 취소로 전송하지 못하면 분당 예약을 회수한다. 토큰 계산 요청과 실제 추론 호출은 검사·계수에서 구분한다.

## 검증 범위

- 연속3회 실패와 수동 재시도: 최신 초안 하나, 전체 실패 이력 보존, 반복 오류에 대한 구조 재검토 지시.
- 역방향 조인 거절, 선언 FK와 상속 group_key 목록, 계정/로그 비율 차이를 유지한 계산.
- 스키마 필드명이 title/default/description인 경우도 보존, 난이도별 필요한 지시와 검색 모드 격리.
- 로컬 입력 거절·분당 대기·키 누락·일일 제한·취소의 실제 전송 수와 계수, 429 이후 무호출 대기.
- 기존 생성·전송·복구·웹 제공자 회귀 및 원래 실패 초안의 요청 크기 재구성.

다른 배포 작업의 변경을 현재 브랜치에 통합했고 그 체크아웃 원본은 보존했다. 운영 봇을 generation-integrated-20261007 이미지로 반영하고 실제 코드 일치를 확인했다. 자동·오프라인 검증과 봇 시작을 실제 출제 품질 승인으로 표시하지 않는다. 실사용 모델 검증 결과는 통합 보고와 Spec036의 남은 검증에서 구분한다.

범위 변경: 운영 작업과의 통합, 실제 운영 스키마 호환, Git 반영 준비를 추가해 전체 작업을6개에서9개로 늘렸다. 출제 성공률이나 교육 품질을 이 진행도의 완료 조건으로 새로 간주하지 않는다. 기존 초급 스레드의 실제 재시도는 API 제한 없이3회 응답을 받았으나 파생 표 설계 검증에서 실패했으며, 이 결과를 성공으로 올리지 않았다.
