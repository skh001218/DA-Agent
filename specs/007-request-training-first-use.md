## 목표

사용자가 직접 사용하며 수정할 수 있는 첫 흐름을 제공한다. Spec 006의 공통 계약을 따른다. 기존 검증 데이터 재사용과 승인된 과제 구성을 조합하며 자유로운 새로운 데이터 생성이나 모든 게임 분야 지원으로 표시하지 않는다.

## 세 가지 사고 과제

- calculation: D1~D7 미재접속의 대상·이탈·제외 인원과 비율을 계산하고 근거·한계 제출.
- review: 공개한 세션 단위 집계 초안의 단위·대상·관측 오류를 확인하고 수정 방안·근거 제출. 공개 오류 SQL은 서버 실제 실행으로 자료의 조회 가능성을 확인.
- design: 재방문 현황을 알아보려는 업무 요청을 정의·비교 기준·관측 한계·추가 확인 계획으로 구체화. SQL 실행을 필수로 하지 않음.

## 첫 사용 완료 조건

요청 → 공개 과제 → 조건 확인/실제 SQL → 선택 저장 → 대화 → 제출 → 시험 운영 리뷰 → 수정·재개를 실행할 수 있다. 자동 코칭은 선택 가능하고 임시 결과를 포함한 원문은 영구 저장하지 않는다. 다음 과제는 최근 유형·저장된 리뷰와 도움 사용을 근거로 이유를 안내하고 사용자가 변경 가능하다. 품질 지표의 첫 집계는 관측 가능한 출제·AI 상태와 시간·사용량에 한정한다.

## 후속 범위

신규 데이터 생성·적재의 요청 연결, 더 다양한 목표·판단·데이터 상황, 의미적 다양성 판정, 누적 학습 상태 편집, 사람 판정 지표 확장, 실제 반복 평가 품질 승인, 다른 PC·ARM과 학습자 5명 파일럿. 첫 구간 완료를 PRD의 11개 전체 완료로 환산하지 않는다.

## 실제 확인과 사용 시작

[검증 기록](../tests/verification-request-training-2026-10-04.md)에 전체 108개·후속 10개 테스트, 실제 Gemini 5회와 세 과제 화면·수정 제출·재개·내보내기 결과를 기록했다. 요청→분석→리뷰의 첫 사용은 가능하다. 삭제 확인창 취소는 브라우저 제어 제한으로 미확인이며 사용자가 검증용 훈련에서 삭제→취소 후 목록 유지 여부를 확인하면 된다. 실제 평가 품질 승인과 학습자 파일럿은 아직 완료하지 않았다.
