## 요구사항

- 기호로 정렬한 표를 사용하지 않고 실제 격자·열 너비·한글 글꼴로 PNG 첨부.
- 데이터 사전은 테이블 이름·한 행의 단위·설명·컬럼·자료형 제공. 자연어 조회 시 모델/SQL 실행 없이 공개 사전 표시.
- 결과는 저장된 성공 실행 값만 표시. 첫 10행 미리보기는 전체 결과와 구분. NULL은 0과 구분하고 빈 결과와 불완전 수집 안내 유지.
- 제목·실행 ID·계산 기준·데이터 버전은 텍스트로 제공. 첨부 실패 시 읽을 수 있는 행별 목록으로 대체하며 재조회하지 않음.
- 저장·평가·SQL·근거 선택 동작 유지.
