## 목적과 범위

사용자는 생성된 문제의 가독성을 높이고자 기본형 템플릿을 선택했다. 생성 분석 문제의 첫 안내와 `/resume`에 동일한 저장 기반 형식을 적용한다. 2026-10-07 추가 배포 요청에 따라 운영 배포와 실제 Discord 재개 검증을 추가하여 전체 작업 수를 3개에서 5개로 변경했다.

새 생성 문제는 공개 업무 설명에 이미 들어 있는 배경·관측 문제·업무 결정·질문·공개 판단 조건·가정을 `intro_sections`에도 저장해 표시 구역을 나눈다. 기존 `objective`, 루브릭, 평가 지문에 사용하는 공개 계약은 변경하지 않는다. 이 표시용 사본은 신규 요구사항이나 정답·생성 그룹·검산 기준 수치를 포함하지 않는다.

이전 생성 문제는 저장된 전체 `objective`를 보존해 동일 구역으로 안내한다. 코칭용 `valid_paths`는 필수 과제로 노출하지 않는다. 추가 모델 호출·기존 데이터 재생성·기간 추정은 하지 않는다.

질문 수와 난이도를 유지한다. 제공 표의 한 행 단위·공개 가정·관측 종료 제외 경계·인정할 한계·합성 자료/검토 상태·검산 범위·실제 저장 출처를 보존한다. 상세 사전·배점은 기존 `/help` 경로에서 열람한다. Markdown 해석과 멘션을 차단하는 전송 정책은 유지하며 일반 텍스트의 구역명·이모지·빈 줄·번호·항목으로 가독성을 높인다.
