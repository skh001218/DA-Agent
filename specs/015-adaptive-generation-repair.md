## 목적과 범위

사용자가 보스 고급 요청 실패를 제시했고, 보스 전용 수정 대신 다른 요청에서도 공통 오류를 줄이도록 요청했다. 특정 보스의 클리어 시간 기본값을 임의로 정하지 않는다. 단일 전투 시간과 최초 성공까지 경과 시간 등 목표의 해석이 핵심적으로 모호하면 요청별 설명/질문으로 명시한다.

새 공통 선언 규칙은 원본에서 계산한 요약, 앞선 필드에서 계산한 종료 시각, 개체·분석 대상별 비중첩 시계열이다. SQL/코드를 모델에서 실행하지 않는다. 자동 검토 탈락 사유는 비공개 보존하며 수정 호출에 전달한다. 형식·데이터 조건 수정은 최대 두 번, 적합성 수정은 최대 한 번, 전체 adaptive 모델 호출은 최대 6회이며 기존 접속 경로의 3회 한도를 유지한다. 해결 불가능한 요청은 실패/질문으로 종료하고 다른 주제로 바꾸지 않는다. 모든 자연어 요청의 무오류 성공을 보장하지 않는다.

## 완료 근거와 한계

[검증 기록](../tests/verification-adaptive-repair-2026-10-05.md)에 실제 모델 요청, 실패한 중간 표본, 원본/요약·시간 검산, 최종 화면과 DB 회귀를 보존한다. 추가 보호 규칙 이전의 중간 성공을 최종 품질 증거로 사용하지 않는다. 초급이 성공하고 고급이 실패하던 특정 사례와 공통 회복 흐름을 검증했으며, 모든 자연어 요청·인과 분석·통계 모델·장르의 완전한 지원을 검증한 것은 아니다.
