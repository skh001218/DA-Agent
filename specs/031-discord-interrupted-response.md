## 요구사항

- 정상 요청은 최초 대기 응답을 직접 수정해 완료 안내를 표시한다. 추가 응답은 기존처럼 비공개 후속 메시지로 보낸다.
- 취소, 종료, 재시작으로 응답을 전달하지 못한 요청의 원래 비공개 응답을 다음 문구로 교체한다.
  > 요청의 응답이 중단되었습니다. /resume으로 저장된 결과를 확인하세요. 요청을 자동으로 다시 실행하지 않습니다.
- 저장·평가 등 업무 작업을 자동 재실행하지 않는다. 응답 중단이 이미 저장한 결과를 되돌리지 않는다.
- 활성 요청은 복구 대상에서 제외한다. 종료 시 남은 요청을 정리하고, 다음 시작 때 이전 실행의 미완료 응답을 복구한다. 일시적인 전송 실패는 30초 간격으로 재시도한다.
- Interaction 수정용 토큰은 전용 로컬 볼륨에만 저장한다. 파일 권한은 600, 디렉터리는 700이며 로그와 훈련 DB에 저장하지 않는다. 응답 완료·복구·만료 후 즉시 삭제한다.
- Discord 토큰 유효 시간(15분)이 지난 메시지는 수정할 수 없다. 이 기능 적용 전에 저장하지 않은 토큰도 복구할 수 없다.

## 검증

- 실제 재시작을 재현하는 별도 응답 관리자 인스턴스와 HTTP MockTransport로 @original 수정 및 토큰 삭제를 검사한다.
- 활성 요청 보호, 정상 응답과 추가 메시지, 취소 전파, 전송 오류 재시도, 429/404, 만료 시 무전송을 검사한다.
- 실제 화면에서는 가벼운 명령의 처리 중 봇을 재시작해 대기 표시 교체를 확인한다.
