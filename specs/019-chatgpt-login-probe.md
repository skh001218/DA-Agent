## 요청과 범위

Gemini 기능을 변경하지 않고 ChatGPT 로그인과 사용자 토큰 연결을 확인한다. 헤더의 Continue with ChatGPT 버튼은 별도 `/api/chatgpt/start`를 호출한다. 상태와 연결 해제도 별도 경로를 사용한다. 기존 `/auth/callback`은 ChatGPT 인증 모듈로 전달한다. ChatGPT가 현재 훈련 공급자일 때 동일 인증 인스턴스를 사용한다.

로그인 성공, 플랜 사용 권한, 실제 AI 호출 성공을 구분한다. 이번 버튼은 로그인과 토큰 권한 연결만 확인하며 모델 호출이나 Gemini 대체를 수행하지 않는다. 토큰은 기존 AuthService의 암호화 저장소에 보관하고 브라우저에는 전달하지 않는다. PKCE, state, nonce, ID 토큰 서명 검증과 토큰 갱신·폐기는 기존 검증된 인증 모듈을 재사용한다.

## 완료 기준

- Gemini 사용 중에도 로그인 버튼을 표시한다.
- 공식 인증 사이트를 새 창으로 열고 분석 입력을 보존한다.
- 콜백이 Gemini가 아닌 ChatGPT 인증 서비스로 전달된다.
- 로그인 여부와 플랜 사용 권한을 별도로 표시하고 로그인 실패는 재시도 가능하다.
- Gemini 설정과 기존 훈련 호출 경로를 유지한다.
- 실제 사용자 승인을 수행하지 않은 경우 성공으로 기록하지 않는다.
