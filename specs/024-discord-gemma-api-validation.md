## 계약

사용자의 Gemma 연결·미검증 테스트 요청에 따라 Google AI Studio의 기존 API 키를 읽기 전용으로 사용한다. 현재 해당 키의 Models API에서 gemma-4-26b-a4b-it와 gemma-4-31b-it를 확인했고 전자를 기본으로 사용한다. DISCORD_MODEL은 웹 GEMINI_MODEL과 분리한다. 키를 출력·커밋하지 않는다. 실제 모델 호출 검증만 수행하며 봇의 서버 등록·사용자 메시지 전송은 Discord 설정이 있을 때 별도 검증한다.

Gemma의 온전한 JSON 코드 블록만 정규화한다. 임의 설명에서 JSON을 추출하지 않는다. 조건/근거/등급 검증은 기존 Discord 모듈을 계속 거친다. 모델 실패·잘못된 JSON·불명확한 조건은 실행/점수를 생성하지 않는다. 실제 표본 통과도 사람의 교육 품질·성장 비교 승인을 대신하지 않는다.

공식 문서: https://ai.google.dev/gemma/docs/core/gemma_on_gemini_api

## 실제 응답에서 확인한 보완

- 완전한 JSON 코드 블록만 정규화한다. Gemma4 추론은 minimal을 사용한다.
- 필수 period_basis/unit 예시를 명시하고, step 필터의 동등한 위치만 정규화한다. 상충 조건은 실행하지 않는다.
- 실제 429 실패와 재시작 가능한 기록 보존을 확인했다. 검증은 간격과 호출 상한을 둔다.
- 최고 등급4의 빈 개선 문구는 결함을 만들지 않고 시스템 제공 다음 연습 안내임을 표시한다. 원래 등급·이유는 유지한다.
- 낮은 등급의 누락 문구/잘못된 근거 ID는 등급을 고정한 1회 보완만 허용한다. 등급 변경 또는 재실패는 보류한다. 이 호출도 일별 한도·사용량에 포함한다.
- 문체 표본은 실제 두 API 응답을 수집한 후 동일한 등급임을 확인했고, 파서 수정 후 해당 응답을 그대로 재검사했다. 최종 제출과 타당한 보류·가설 수정은 수정 후 API를 다시 호출했다.
- 초기 실패 표본도 삭제하지 않고 artifacts에 보존한다. 사람 승인과 실제 Discord 검증은 자동 표본 통과로 대체하지 않는다.

## 본인 단독 사용 범위 승인 (2026-10-06)

사용자는 현재 본인만 사용할 것이므로 실제 Discord 핵심 흐름을 완료로 두기로 했다. 기존 단일 계정 시작·조회·SQL·빈 결과·중단/재개·위치 거부 화면과 격리 회귀를 근거로 완료 조건을 조정했다. 새 테스트를 수행하거나 두 사용자·실제 삭제/보관/403을 통과한 것으로 기록하지 않는다. 해당 오류는 후속 검증으로 보존하고, 다중 사용자 확대 전 접근 분리를 확인한다. 교육·보고·평가의 사람 검토와 성장 비교 승인은 Spec021/023에 남아 있다. 과거 검증 한계와 수동 확인 목록은 당시 범위의 기록이다.
