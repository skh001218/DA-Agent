## 목적과 범위

기존 Gemma 실험에서 확인한 모델 독립적인 문제를 최신 Codex CLI 코드에 선별 이관한다. 총 자료 행 수는 파생 표까지 포함해 2,000행으로 제한한다. 외래 키, 수치 범위, 집계, 비교 차원, 비율과 관측되지 않은 리텐션 주장에 정확한 오류 위치를 전달한다. 의미 검토에서 거절된 설계는 자동 재사용하지 않고 전체 Recipe 수정을 요청한다.

CLI 연결, 진행 표시, 공개 자료 계약과 기존 모델 호출 한도를 유지한다. 검증 규칙을 완화하지 않는다. Gemma 전송·쿼터 설정과 RecipePatch 프로토콜은 이관하지 않는다. 변경 이력은 `codex/analysis-recovery-backup`의 `9efe9f1`로 보존한다. 초기 정리는 운영 배포를 포함하지 않았으며, 아래의 추가 요청으로 운영 반영 범위를 확장했다.

## 운영 반영 요청 (2026-10-07)

사용자가 운영 반영을 요청하여 PR·CI·main 병합·main CI·지정 배포 명령·운영 코드 확인을 범위에 추가했다. 기존 main의 PDF 개선은 유지한다. 원래 작업 폴더의 아카이브 차단은 운영 배포를 막지 않는다. 병렬 기능의 Spec056 번호를 피하려고 이번 문서를 Spec057로 옮겼다.
