## 요구사항

사용자가 추천한 구성으로 줄이기를 요청했다. 신규 안내는 훈련 ID·빈 저장 건수·전체 사전·분석 방법 힌트·배점과 등급·전체 명령을 나열하지 않는다. 재개 시 기록이나 상태 변화가 있으면 진행 상태를 추가로 표시한다.

가입 주간은 과제의 start/end에서 계산하며 end_exclusive를 반영한다. 유입 채널은 현재 지원하는 tutorial 대표 과제의 organic/ads다. 재도전 중복 가능성과 합성 데이터의 수집 한계는 보존한다.

/help의 kind에 데이터 사전(data_dictionary), 평가 기준(evaluation_criteria), 전체 명령(commands)을 추가한다. 이 열람에는 text가 필요하지 않으며 모델 호출과 도움받은 성과 기록이 발생하지 않는다. 완료·중단 상태에서도 공개 자료를 열람할 수 있다. 기존 사전과 평가 계약, 실제 평가 방식은 유지한다.

## 운영 반영

운영 봇은 discord-mvp 작업 폴더에서 실행되고 있어 해당 폴더에 동일 변경 부분만 반영했다. 기존 권한 검사 변경은 보존했다. 실행 컨테이너 반영 및 재시작, 재생성에 사용할 이미지 빌드를 수행했다. 기존 메시지 기록은 보존하며 새 출제와 재개부터 간결한 안내를 적용한다.

재시작 직후 첫 /resume은 응답 시간 초과였다. Gateway 연결 복구 후 두 번의 재개 응답과 데이터 사전 열람을 실제 화면에서 확인했다. 새 훈련 데이터 생성과 DB 전체 회귀는 이번 표시 변경의 검증 범위에 포함하지 않았다.
